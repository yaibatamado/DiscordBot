Chính Sách Bảo Mật Privacy Policy

Trang này giải thích Moonlight có thể xử lý dữ liệu nào khi hoạt động trong máy chủ Discord.

This page explains what data Moonlight may process while operating in Discord servers.

Moonlight Discord Bot Không bán dữ liệu người dùng No user data selling

1. Dữ liệu có thể được lưu

Moonlight có thể lưu một số định danh Discord cần thiết cho tính năng bot, ví dụ: user ID, server ID, cấu hình kênh, tiến trình pet, vật phẩm inventory, coin, trạng thái party hoặc dữ liệu tiện ích tương tự.

2. Dữ liệu không cố ý lưu

Moonlight không cố ý lưu mật khẩu, thông tin thanh toán, token Discord riêng tư hoặc toàn bộ lịch sử tin nhắn. Một số lệnh có thể đọc nội dung tin nhắn tạm thời chỉ để thực hiện yêu cầu của người dùng, ví dụ như dọn tin nhắn.

3. Cách dữ liệu được sử dụng

Dữ liệu được dùng để cung cấp tính năng Moonlight, giữ tiến trình, hỗ trợ quản trị server, hiển thị giao diện tương tác và cải thiện trải nghiệm sử dụng bot.

4. Chia sẻ dữ liệu

Moonlight không bán dữ liệu người dùng. Dữ liệu chỉ có thể được xử lý bởi hạ tầng cần thiết cho việc vận hành, bảo trì, bảo mật hoặc khi có yêu cầu pháp lý hợp lệ.

5. Xóa dữ liệu

Người dùng hoặc chủ server có thể yêu cầu xóa dữ liệu bot đã lưu bằng cách liên hệ chủ bot qua server hỗ trợ hoặc repository nơi Moonlight được duy trì.

6. Thay đổi chính sách

Chính sách này có thể được cập nhật theo thời gian. Việc tiếp tục sử dụng Moonlight nghĩa là bạn chấp nhận phiên bản mới nhất.

7. Liên hệ

Nếu có câu hỏi về quyền riêng tư hoặc yêu cầu xóa dữ liệu, hãy liên hệ chủ bot qua server Discord hỗ trợ hoặc repository của Moonlight.

1. Data we may store

Moonlight may store limited Discord identifiers required for bot features, such as user IDs, server IDs, channel settings, pet progress, inventory items, coins, party status, or similar utility data.

2. Data we do not intentionally store

Moonlight does not intentionally store passwords, payment information, private Discord tokens, or full message history. Some commands may temporarily read message content only to perform a requested action, such as message cleanup.

3. How data is used

Data is used to provide Moonlight features, keep progress, support server moderation, display interactive interfaces, and improve the bot experience.

4. Data sharing

Moonlight does not sell user data. Data may only be processed by infrastructure required for hosting, maintenance, security, or valid legal compliance.

5. Data removal

Users or server owners may request removal of stored bot data by contacting the bot owner through the support Discord server or the repository where Moonlight is maintained.

6. Changes to this policy

This policy may be updated over time. Continued use of Moonlight means you accept the latest version.

7. Contact

For privacy questions or data removal requests, contact the bot owner through the support Discord server or Moonlight repository.

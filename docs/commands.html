Commands

Danh sách lệnh chính thức của Moonlight, kèm cách dùng, quyền cần có và ghi chú để bạn quản lý server dễ hơn.

The official Moonlight command reference, with usage, required permissions, and notes for smoother server management.

Hệ thốngSystem

/help
?help

Mở bảng hướng dẫn nhanh trong Discord. Dùng khi bạn muốn xem toàn bộ nhóm lệnh hiện có mà không cần lên website.

Shows the quick help panel inside Discord. Use it when you want the available command groups without opening the website.

/moonlight

Hiển thị thông tin bot, số server, uptime, các lệnh chính và nút mời bot hoặc vào server hỗ trợ.

Shows bot information, server count, uptime, main commands, and buttons for inviting the bot or joining support.

/check

Kiểm tra quyền quan trọng của Moonlight trong server và kênh hiện tại. Lệnh này giúp phát hiện nhanh thiếu quyền quản lý kênh, quản lý tin nhắn, gửi embed hoặc voice.

Checks Moonlight's important permissions in the current server and channel. This helps detect missing channel, message, embed, or voice permissions quickly.

/avatar [user]
?av [@user]

Xem avatar của bạn hoặc người được chọn. Nếu không chọn user, bot sẽ lấy avatar của người dùng lệnh.

Shows your avatar or the selected user's avatar. If no user is selected, Moonlight uses the command author.

/server
?server

Xem thông tin server bằng embed: tên server, chủ server, số thành viên, kênh, role và các dữ liệu tổng quan.

Shows server information in an embed: server name, owner, member count, channels, roles, and overview details.

/dbstatus

Kiểm tra trạng thái kết nối SQL Server. Hữu ích khi bạn muốn biết bot có đang kết nối database ổn không.

Checks SQL Server connection status. Useful for confirming whether the bot can reach the database.

/settings view
/settings voice-log enabled:true

Xem hoặc chỉnh thiết lập server. Hiện tại dùng để bật/tắt thông báo ai vào/rời voice, và trạng thái được lưu trong SQL Server.

Views or updates server settings. Currently used to enable or disable voice join/leave notifications, stored in SQL Server.

/autoreply add trigger:"hi" reply:"hello {user} || hi {username}" channel:#chat
/autoreply list
/autoreply edit/remove/toggle/channel

Tạo phản hồi tự động cho server. Khi tin nhắn khớp trigger, Moonlight sẽ trả lời bằng nội dung đã lưu trong SQL Server.

Creates automatic server replies. When a message matches a trigger, Moonlight responds with the saved SQL Server response.

  • Cần quyền quản lý server.
  • Requires manage server permission.
  • Mode hỗ trợ: contains, exact, starts_with.
  • Supported modes: contains, exact, starts_with.
  • Dùng || để random nhiều câu trả lời.
  • Use || to randomize multiple replies.
  • Có thể giới hạn autoreply vào một channel bằng option channel.
  • You can limit an autoreply to one channel with the channel option.
  • Placeholder: {user}, {username}, {server}, {channel}.
  • Placeholders: {user}, {username}, {server}, {channel}.

/letter send recipient:"An" message:"..." song:"505 - Arctic Monkeys" tag:nostalgia
/letter browse
/letter mine/edit/view/random/delete

Gửi một public song letter vào kênh hiện tại. Moonlight sẽ cho xem preview riêng tư trước, sau đó bạn bấm Post hoặc Cancel. /letter browse xem toàn bộ thư có phân trang, có thể lọc theo người nhận hoặc tag.

Sends a public song letter to the current channel. Moonlight shows a private preview first, then you choose Post or Cancel. /letter browse shows all letters with pagination and optional recipient/tag filters.

  • Khi nhập song, Moonlight gợi ý bài hát kiểu Instagram Notes và tự lấy ảnh album/link nghe nếu tìm thấy.
  • While typing song, Moonlight suggests tracks like Instagram Notes and can auto-fill album art/listening link.
  • Mặc định ẩn danh, có thể đặt anonymous:false để hiện người gửi.
  • Anonymous by default, with anonymous:false available to show the sender.
  • Có nhiều tag như love, sad, miss_you, thanks, sorry, crush, friendship, healing, hope, goodbye, memories, confession, comfort...
  • Includes many tags such as love, sad, miss_you, thanks, sorry, crush, friendship, healing, hope, goodbye, memories, confession, comfort...
  • /letter mine xem thư bạn đã gửi. /letter edit sửa thư. Có cooldown chống spam khi đăng.
  • /letter mine shows your posted letters. /letter edit edits a letter. Posting has an anti-spam cooldown.
  • Người gửi hoặc mod có quyền quản lý tin nhắn có thể sửa/xóa letter.
  • The sender or a moderator with Manage Messages can edit/delete a letter.

Voice & nhạcVoice & Music

/join

Cho Moonlight vào kênh voice bạn đang đứng. Dùng để treo bot trong voice hoặc hỗ trợ các thông báo voice.

Makes Moonlight join your current voice channel. Use it to keep the bot present in voice or support voice notifications.

/leave

Cho Moonlight rời voice channel hiện tại trong server.

Makes Moonlight leave the current voice connection in the server.

/music

Hiển thị hướng dẫn dùng Jookie Music, dành cho server muốn dùng bot nhạc riêng bên cạnh Moonlight.

Shows the Jookie Music guide for servers that use a dedicated music bot alongside Moonlight.

Quản trịModeration

/mod clear [amount] [user] [userid] [time]

Xóa tin nhắn trong kênh hiện tại. Có thể lọc theo user, user ID và mốc thời gian như 1 giờ, 6 giờ, 12 giờ, 24 giờ, 3 ngày hoặc 7 ngày.

Deletes messages in the current channel. You can filter by user, user ID, and time range such as 1 hour, 6 hours, 12 hours, 24 hours, 3 days, or 7 days.

  • Cần quyền quản lý tin nhắn.
  • Requires manage messages permission.
  • Discord không cho bulk delete tin nhắn quá 14 ngày, nên bot sẽ xóa tối đa phần có thể xóa.
  • Discord does not allow bulk deleting messages older than 14 days, so the bot removes the maximum deletable set.

/mod kick user:@user

Kick một thành viên khỏi server. Thành viên có thể vào lại nếu có link mời hợp lệ.

Kicks a member from the server. The member can rejoin later with a valid invite link.

/mod ban user:@user
/mod unban userid:id

Ban hoặc gỡ ban thành viên. Lệnh unban dùng user ID, phù hợp khi user không còn trong server.

Bans or unbans a member. The unban command uses a user ID, which works even when the user is no longer in the server.

/mod timeout user:@user time:10 reason:"spam"
/mod untimeout user:@user

Timeout hoặc gỡ timeout thành viên. Có thể thêm lý do để embed kết quả rõ ràng hơn.

Timeouts or removes timeout from a member. You can include a reason for a clearer result embed.

/warn user:@user reason:"spam"

Gửi cảnh cáo tạm thời cho user. Lệnh này không lưu lịch sử vào database.

Sends a temporary warning to a user. This command does not store warning history in the database.

/mod slowmode seconds:10

Đặt slowmode cho kênh hiện tại, giúp giảm spam khi chat quá nhanh.

Sets slowmode for the current channel to reduce rapid spam.

/mod lockchannel
/mod unlockchannel

Khóa hoặc mở khóa quyền gửi tin nhắn của @everyone trong kênh hiện tại.

Locks or unlocks @everyone's send-message permission in the current channel.

Ghi chú: các lệnh quản trị cần bot có quyền phù hợp và role của bot phải cao hơn role của mục tiêu. Note: moderation commands require the bot to have the correct permissions, and the bot role must be higher than the target role.

Thiết lậpSetup

/setup voice

Gửi panel quản lý phòng voice riêng vào kênh hiện tại. Người dùng bấm nút để tạo voice riêng và quản lý phòng bằng các nút tiếng Anh.

Sends the private voice room control panel to the current channel. Users press buttons to create and manage their own voice room.

  • Các thao tác chính: Name, Limit, Privacy, Invite, Kick, Claim, Transfer, Delete.
  • Main actions: Name, Limit, Privacy, Invite, Kick, Claim, Transfer, Delete.
  • Bot cũng báo join/leave ngay trong chat của kênh voice.
  • The bot also announces join/leave activity inside the voice channel chat.

/setup channel

Gửi panel tạo text channel cá nhân. Mỗi thành viên có thể tạo phòng riêng để chat, gửi ảnh hoặc lưu tài liệu.

Sends the private text channel panel. Each member can create a personal room for chatting, images, or saved notes.

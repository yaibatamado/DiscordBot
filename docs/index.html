Tính năngFeatures

Tập trung vào những thứ server cần mỗi ngày: quản trị rõ ràng, voice tiện, lệnh sạch và giao diện embed đẹp.

Built around daily server needs: clear moderation, practical voice tools, clean commands, and polished embeds.

▣

Server Tools

Xem thông tin server, avatar, trạng thái bot, hướng dẫn lệnh và các trang điều khoản/chính sách rõ ràng.

View server info, avatars, bot status, command help, and clear terms/privacy pages.

◉

Voice Rooms

Tạo phòng voice hoặc text riêng bằng panel `/setup`, đổi tên, giới hạn người dùng, mời, chặn, chuyển chủ và xóa phòng.

Create private voice or text rooms with `/setup`, then rename, limit, invite, block, transfer, or delete them.

◆

Moderation

Các lệnh mod cho clear tin nhắn, warn, timeout, ban, kick, slowmode, khóa hoặc mở khóa kênh.

Moderation commands for message cleanup, warnings, timeout, ban, kick, slowmode, and channel lock/unlock.

✦

Auto Replies

Tạo phản hồi tự động theo trigger, giới hạn theo kênh và random nhiều câu trả lời bằng `/autoreply`.

Create trigger-based replies, limit them by channel, and randomize response text with `/autoreply`.

♪

Moonlight Letters

Gửi public song letter vào kênh hiện tại, tìm theo tên người nhận, xem chi tiết hoặc mở link bài hát.

Send public song letters to the current channel, search by recipient, view details, or open the song link.
